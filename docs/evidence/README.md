# Evidencia de cámara

Esta carpeta recibe notas breves de pruebas reales. No guardar video ni datos
personales por defecto.

## Plantilla

```text
fecha:
dispositivo:
navegador/Android:
resolución:
iluminación:
fps inferencia:
fps render:
calidad:
latencia percibida:
frames perdidos:
swaps izquierda/derecha:
inversión de pulgar:
resultado de replay:
observaciones:
```

Una observación debe describir acción, resultado y condición de reproducción.
Si aparece una regresión, enlazar el caso sintético o test que la cubre.
